        User Guide

        Rooms
        Enter a nickname to create a room. Share its code, or enter a friend's code and select Join Room. The host starts with at least two players.
        Duration
        The host chooses 1, 2, 5 or 10 minutes. Questions continue until time runs out.
        Answers & scoring
        Type a number and press Enter or the arrow. Each correct answer earns one point; an incorrect answer advances to the next question. The server confirms scores and the deadline.
        Results
        The highest score wins. Equal highest scores share the win. The host can select Play Again for a new round.
        Rankings
        Guest play is available. Sign in with Google before the round starts to qualify for Weekly and All-Time rankings for that duration. Stay connected and keep the same account throughout the round.
